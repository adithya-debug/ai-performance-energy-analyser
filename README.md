# AI Performance Energy Analyzer

## 📌 Project Description

AI Performance Energy Analyzer is a Python-based project that compares different machine learning models based on their performance.

The project measures:

- Model Accuracy
- Execution Time
- CPU Usage
- Memory Usage

## 🤖 Machine Learning Models

The project compares:

1. Logistic Regression
2. Random Forest
3. Decision Tree
4. K-Nearest Neighbors
5. Support Vector Machine

## 📊 Performance Comparison

The current results include:

| Model | Accuracy |
|---|---:|
| Logistic Regression | 96.67% |
| Random Forest | 90.00% |
| Decision Tree | 93.33% |
| K-Nearest Neighbors | 100.00% |
| Support Vector Machine | 96.67% |
